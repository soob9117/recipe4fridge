# PRD 1단계: 냉장고 사진에서 식재료 인식

## 1. 배경과 목표

냉장고 안에 무엇이 있는지 일일이 적는 일은 번거롭다. 사용자가 냉장고 사진 한 장을 올리면 AI 이미지 모델이 식재료를 찾아 목록으로 보여 주고, 사용자가 그 목록을 확인하고 고칠 수 있게 한다. 이 목록은 2단계(레시피 생성)의 입력이 된다.

**목표**
- 사진 한 장으로 식재료 목록을 얻는다.
- 인식 결과가 틀려도 사용자가 바로 고칠 수 있다.
- 무료 모델의 잦은 실패에도 사용자가 무슨 일이 일어났는지 알 수 있다.

**범위 밖**
- 레시피 추천(2단계), 회원과 저장(3단계)
- 유통기한 인식, 바코드 인식, 여러 장 동시 업로드

## 2. 사용자 흐름

1. 사용자가 웹 화면에서 냉장고 사진을 고른다.
2. 화면에 사진 미리보기가 보인다.
3. "식재료 인식" 버튼을 누르면 진행 중 표시가 나타난다.
4. 인식이 끝나면 **사진과 같은 화면에서** 식재료 목록이 보여, 사용자가 사진과 목록을 비교할 수 있다.
5. 사용자가 목록에서 항목을 고치거나, 지우거나, 새로 추가한다.
6. 확정된 목록은 2단계로 넘길 수 있는 상태로 유지된다.

## 3. 기능 요구사항

### 3.1 사진 업로드
- 허용 형식: JPG, PNG, WEBP
- 최대 크기: 10MB. 넘으면 업로드 전에 안내 문구를 보여 준다.
- 모델에 보내기 전에 긴 변을 1568px 이하로 줄여 전송량과 응답 시간을 줄인다.
- 사진은 base64 data URL(`data:image/...;base64,...`)로 API에 보낸다.

### 3.2 식재료 인식 (AI 이미지 모델)
- 기본 모델: `nvidia/nemotron-3.5-super-vl:free`
- 예비 모델(앞 모델이 실패하면 차례로 시도): `google/gemma-4-26b-a4b-it:free`, `google/gemma-4-31b-it:free`
- 모델에는 아래 JSON 형식으로만 답하라고 지시하고, 이름은 한국어로 쓰게 한다.

```json
{
  "ingredients": [
    {"name": "달걀", "quantity": "6개", "category": "유제품·달걀"}
  ]
}
```

- `category`는 채소, 과일, 육류, 해산물, 유제품·달걀, 소스·양념, 음료, 기타 중 하나로 한다.
- 수량을 알 수 없으면 `quantity`는 빈 문자열로 둔다.
- 앱은 응답을 파싱할 때 ```json 코드 블록 감싸기를 벗겨 낸다.
- 같은 이름의 식재료가 여러 번 나오면 하나로 합친다.

### 3.3 결과 확인과 편집
- 목록은 표 형태로 보여 주고, 각 행에서 이름과 수량을 고칠 수 있다.
- 행마다 삭제 버튼이 있고, 목록 아래에 새 식재료를 추가하는 입력란이 있다.
- 식재료가 하나도 인식되지 않으면 "식재료를 찾지 못했습니다. 다른 사진을 올리거나 직접 추가해 주세요."를 보여 준다.

### 3.4 오류 처리
OpenRouter 무료 모델은 공급자 쪽 실패가 잦으므로(2026-10-23 연결 시험에서 404, 429 확인) 아래를 지킨다.
- 429, 404, 5xx, 시간 초과는 재시도하고, 같은 모델에서 계속 실패하면 예비 모델로 넘어간다.
- 400, 401, 402, 403은 재시도하지 않는다. 401은 "API 키를 확인해 주세요."로 안내한다.
- HTTP 200이어도 응답에 `choices`가 없으면 실패로 처리한다.
- JSON 파싱에 실패하면 같은 모델로 한 번 더 요청하고, 그래도 실패하면 다음 모델로 넘어간다.
- 요청 timeout은 180초로 한다.
- 모든 모델이 실패하면 실패 사실과 마지막 원인(예: "무료 모델이 혼잡합니다")을 정직하게 보여 준다. 빈 목록을 성공처럼 보여 주지 않는다.

## 4. 비기능 요구사항
- API 키는 `.env`의 `OPENROUTER_API_KEY`(배포 시에는 배포 환경의 Secrets)에서만 읽는다. 화면, 로그, 오류 메시지에 키를 노출하지 않는다.
- 인식 중에는 버튼을 비활성화해 중복 요청을 막는다. 무료 티어에는 하루 호출 한도가 있다.
- 화면 문구는 모두 한국어로 한다.
- 어떤 모델이 결과를 냈는지 화면 한쪽에 작게 표시한다(문제 추적용).

## 5. 완료 기준
- [ ] `test_assets/sample.png`가 아닌 실제 냉장고 사진으로 식재료가 3개 이상 인식된다.
- [ ] 인식 결과가 사진과 같은 화면에 보인다.
- [ ] 목록의 항목을 수정, 삭제, 추가할 수 있다.
- [ ] 기본 모델을 일부러 잘못된 이름으로 바꾸면 예비 모델로 넘어가 결과가 나온다.
- [ ] 잘못된 API 키로 실행하면 키 확인 안내가 보이고 앱이 멈추지 않는다.
